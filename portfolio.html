About

The work I care about is slow and mostly invisible from the outside. You read a function, guess at what it does, test the guess, and usually find out you were wrong. Then you read it again. The interesting parts are rarely where you expect them to be.

I write in Python when something needs a script, a parser, or automation around a tool that was not built to be automated. I know HTML and CSS well enough to build a clean page, and JavaScript well enough to not break it.

I'm 16, in Dortmund. German and English both fluent, Russian I can understand but not really speak. Off screen it's music, and games when there's time.
